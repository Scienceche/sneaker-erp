摄像头打不开？

1. 权限被拒(permission denied)：点 Chrome 地址栏左侧的锁/ⓘ 图标 → 权限 → 摄像头 → 允许 → 刷新页面；
2. 本地文件打开无法扫码：安卓 Chrome 禁止本地文件(file://)调用摄像头，必须通过 在线网址(https) 打开本应用；
3. 摄像头被占用：关闭微信/其他扫码App后重试；
4. 浏览器地址栏输入 chrome://settings/content/camera 检查全局是否禁用；
5. 仍不行就用下方手动输入条码，其他功能不受影响。

支持 EAN-13 / EAN-8 / UPC / Code128 / Code39 / ITF / 二维码。上方可切换扫码动作：询问=弹面板自选售出/入库/出库；快速售出/入库=直达对应面板；扫码加购=直接加入购物车开单。确认后可连续扫码。新条码自动带入新增表单。

设置 · 备份

数据备份

CSV 列与导出一致：条码,品牌,型号,颜色,货号,尺码,进价,售价,库存,预警值；按 条码+尺码 匹配——已有则更新信息并累加库存，没有则建档。

数据保存在手机浏览器本地(localStorage)。建议每周导出一次 JSON 备份；换手机时用导入恢复。

识货 / 得物 辅助建档

识货、得物没有开放的商品查询接口，本应用用「比价直达」的方式接入：
1. 扫到新条码建档时，点表单里的 识货比价 / 得物比价，按货号直达搜索结果页（手机上会唤起对应App）；
2. 在识货/得物里确认商品后，把货号(如 DD1391-100)、名称、配色、发售价填进表单保存；
3. 之后同款鞋只需改尺码快速建档，扫码/输货号都能直接识别库存。
行情价：商品表单可记录「得物行情价 / 海外行情价(StockX/GOAT)」并保留更新时间，首页「行情估值」按 得物价×在库 自动算浮盈与溢价率——借鉴得物价格追踪/国内外比价的玩法，数据由你维护、存本机。
本应用数据完全存本机，不经过任何服务器，因此无法在扫码瞬间自动联网带出商品资料——这也是它离线可用的原因。

海外行情自动刷新 · GOAT 数据源

先在电脑上双击仓库里的 price-service/启动行情服务.bat(需 Node.js,GOAT 公开数据源国内直连)。按货号精确匹配、按欧码取对应尺码人民币最低价,无货号的商品自动跳过。手机浏览器受跨域限制连不到电脑服务,建议在电脑端刷新,再用「导出/导入备份」同步到手机。
AI拍照识别也走本服务:在 price-service/config.json 填入大模型 key 即可(参考 config.example.json;智谱 open.bigmodel.cn 的 glm-4v-flash 免费),拍鞋盒/鞋标自动填品牌/型号/配色/货号/尺码。
得物行情为什么不能自动刷新?得物无公开接口,老签名(2019小程序版)已封禁,新签名未公开,识货聚合接口也有WAF防护——所以得物价走「比价按钮 + 商品列表「行情」快填」半自动方式。

得物行情自动刷新 · 本地扩展源

用法:点「① 开始采集」→ 去微信的共鞋小程序里搜索你要的货号(可连续查多个)→ 回来点「② 完成采集」→ 自动刷新得物行情。已登记的货号每 6 小时自动刷新一次(共鞋有查询配额,冷却避免浪费次数);新货号只需在共鞋里查一次(终身有效)。采集期间系统流量走本地代理,查完记得点②恢复。使用你自己的共鞋账号,仅供个人行情参考。

手机安装说明

推荐 · 在线版（支持扫码）
1. 手机 Chrome 打开本应用的在线网址(GitHub Pages 地址)；
2. 首次点"开启摄像头扫码"时选择允许摄像头权限；
3. Chrome 菜单(⋮) →「添加到主屏幕 / 安装应用」，之后从桌面图标进入，全屏运行、离线可用；
4. 电脑浏览器同样可用。

离线文件版（不能扫码）
把 index.html 发到手机用 Chrome 打开，除扫码外的功能均可用；本地文件模式浏览器禁止调用摄像头，扫码请用在线版。
