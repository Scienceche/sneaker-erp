# 球鞋ERP · 扫码进销存

手机可直接安装的单文件球鞋进销存系统（PWA），支持摄像头扫码录入、开单收银、退货与利润统计。

**在线版（扫码需此地址）**：<https://scienceche.github.io/sneaker-erp/>

## 功能

- 扫码作业：摄像头扫鞋盒条码（EAN-13/EAN-8/UPC/Code128/Code39/ITF/二维码）。四种扫码动作可切换：
  - **询问**：识别后弹出操作面板，自选售出/入库/出库（带数量步进器、价格、备注）
  - **快速售出 / 快速入库**：识别后直达对应面板，确认后可继续扫下一件（连续扫码）
  - **扫码加购**：识别后直接加入购物车开单
  - 多尺码条码自动列出各码库存供点选；新条码自动带入新增表单；支持手电筒、前后镜头切换；无法扫码时可手动输入
- 识货/得物辅助建档：建档表单一键按**货号**直达识货/得物搜索（手机上唤起App），确认商品后回填货号/名称/发售价；同款不同码共用货号，扫鞋盒货号条码也能识别。识货/得物未开放查询API，本应用零后端、数据全存本机，故采用比价直达而非自动带出
- 行情价与库存估值：商品可记录**得物行情价（国内）与海外行情价（StockX/GOAT，表单内一键比价直达）**并保留更新时间；首页「行情估值」按 得物行情×在库 自动计算行情总值、浮盈与溢价率（CSV 导入导出同步支持行情列）
- 开单收银（购物车）：搜索加购、逐项数量/单价调整、合计与预计毛利实时计算，一键结算生成订单
- 订单管理：历史订单列表、订单详情、**按单项或整单退货**（退货自动回补库存、冲减销售）、小票打印（`window.print`）
- 商品库存：品牌/型号/颜色/货号/尺码/进价/售价/预警值，搜索 + 低库存/缺货筛选；"40-45" 批量尺码一次建档
- 首页看板：今日销售额/利润/单数（退款自动冲减为净额）、库存成本、SKU 数；**近7日销售趋势折线图**（纯 Canvas 无依赖）与**品牌销售占比**（近30天）
- 低库存预警：断货/低库存分层提示，点击预警行直达补货入库
- 进销记录：销售/退货/入库/出库/调整全流水可筛选，售出自动算毛利，退货记负向流水
- 数据备份：JSON 导入导出、商品/记录 CSV 导出、**商品 CSV 批量导入**（与导出格式一致，按 条码+尺码 自动合并建档/补货）
- 数据全部存在手机本地（localStorage），离线可用，不经任何服务器

## 使用（手机）

1. 用 Chrome 打开本站地址（GitHub Pages）
2. 首次扫码时允许摄像头权限
3. 菜单 →「添加到主屏幕」，像 App 一样全屏离线使用

> 注意：本地文件（file://）方式打开时浏览器禁止调用摄像头，扫码需通过在线地址使用。

## 数据说明

- 数据结构：`{ products, records, orders, meta }` 存于 localStorage 单键 `sneaker_erp_v1`；旧版本数据打开即自动迁移（补齐 orders 等字段），无需手动处理
- Service Worker 采用缓存优先策略：**发版更新时请把 `sw.js` 里的 `CACHE` 版本号 +1**，否则老用户可能停留在旧缓存

## 海外行情自动刷新(可选 · 本地行情服务)

电脑上跑一个零依赖小服务,ERP 一键把在库商品的「海外行情价」刷成 GOAT 实时分码最低价(人民币):

1. 电脑安装 [Node.js](https://nodejs.org/zh-cn)(LTS 即可)
2. 双击仓库里的 `price-service/启动行情服务.bat`(或 `node price-service/mkt-server.js`)
3. 打开 ERP → 设置 → 海外行情自动刷新 → 「测试连接」→「刷新在库商品海外行情」

按**货号**精确匹配、按**欧码**取对应尺码价格;无尺码商品取全码最低价。数据来自 GOAT 前端公开搜索接口(与开源 Sneaks-API 同性质),非官方接口、仅供个人行情参考。手机浏览器因跨域限制连不到电脑服务:建议电脑端刷新后,用「导出/导入备份」把数据同步到手机。

**本地扩展源**:行情服务支持可选扩展包(同目录 `*-local.js`,自动加载、不入 Git)。装了扩展后 ERP 设置页会多出「国内得物行情」卡片,可按扩展包提供的方式自动刷新得物行情价;未安装不影响任何功能。

## 部署到手机可安装的在线版（GitHub Pages）

1. Fork / 推送到 GitHub 仓库
2. 仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)`，保存
3. 约 1 分钟后访问 `https://<用户名>.github.io/sneaker-erp/`，手机 Chrome 打开 → 菜单 →「添加到主屏幕」即可像App一样使用（含扫码）

## 开发

纯静态单页应用，无依赖、无构建：`index.html` + `manifest.json` + `sw.js`。

本地调试：任意静态服务器（如 `python -m http.server`）后浏览器打开 `http://127.0.0.1:8000`。改动 `index.html` 后若页面未更新，是 SW 缓存所致（DevTools → Application → Clear storage，或临时注释 SW 注册）。
