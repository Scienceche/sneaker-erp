# 球鞋ERP · 扫码进销存

手机可直接安装的单文件球鞋进销存系统（PWA），支持摄像头扫码录入。

## 功能

- 扫码作业：摄像头扫鞋盒条码（EAN-13/EAN-8/UPC/Code128/Code39/ITF/二维码），识别后直接入库/售出/出库；新条码自动带入新增表单；支持手电筒、前后镜头切换；无法扫码时可手动输入
- 商品库存：品牌/型号/颜色/货号/尺码/进价/售价/预警值，搜索 + 低库存/缺货筛选
- 销售记录：售出自动算毛利，全流水可筛选，今日销售/利润/单数汇总
- 首页看板：库存成本、SKU 数、低库存预警、最近动态
- 数据备份：JSON 导入导出、商品/记录 CSV 导出（Excel 中文兼容）
- 数据全部存在手机本地（localStorage），离线可用，不经任何服务器

## 使用（手机）

1. 用 Chrome 打开本站地址（GitHub Pages）
2. 首次扫码时允许摄像头权限
3. 菜单 →「添加到主屏幕」，像 App 一样全屏离线使用

> 注意：本地文件（file://）方式打开时浏览器禁止调用摄像头，扫码需通过在线地址使用。

## 开发

纯静态单页应用，无依赖、无构建：`index.html` + `manifest.json` + `sw.js`。
